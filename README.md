# Experiment 2: Prompt Engineering Comparison

## Aim
To compare a baseline prompt with an enhanced prompt and demonstrate how role assignment, context, analogy, and output format instructions influence the responses generated by a Large Language Model.

## Technologies Used
- Python
- Google Colab
- Google Gemini API
- Google Gen AI SDK

## Procedure
1. Initialize the Gemini API client using a securely stored API key.
2. Define a baseline prompt.
3. Define an enhanced prompt with role, context, and formatting instructions.
4. Send both prompts to the same Gemini model.
5. Display and compare the generated responses.

## Output
The baseline and enhanced responses are displayed, along with a comparison of response length and prompt specificity.

## Result
The experiment demonstrates how clear instructions and constraints can guide a language model to generate more targeted and structured responses.
